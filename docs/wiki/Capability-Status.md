# Capability Status

The [current roadmap/checklist](../../work/roadmaps/CAPABILITY_CHECKLIST.md)
links each capability to its source evidence and names the objective it serves.
Read the **source reported** and **successor evidence** columns separately.

For a historical comparison, pin a dated subsystem inventory, such as the
[original capability snapshot](https://github.com/BigCatMellow/MAPS_Lean/blob/605ce610e0be3334d1da7af2a7c6f5912b6cc05f/docs/wiki/Capability-Status.md).
Its counts describe that snapshot. For a successor decision, inspect the
production call path / real behavior required by the row, with a real caller/path,
not only a unit test. For example, testing a denial inside a guard and
observing an ordinary operation reach that guard answer different questions.
