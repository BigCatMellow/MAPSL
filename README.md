# MAPSL

A provider-neutral operating system around capable AI workers: task truth,
bounded authority, reasoning and planning, coordination, verification, recovery,
continuity, durable evidence and controlled learning.

**Migration in progress.** This candidate is not yet the accepted successor.
The original [MAPS_Lean](https://github.com/BigCatMellow/MAPS_Lean) remains intact and operational.
