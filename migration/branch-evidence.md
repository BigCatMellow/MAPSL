Source main was pinned at `605ce610e0be3334d1da7af2a7c6f5912b6cc05f`. Every branch listed below was checked using the recorded object ID. The 102 refs include aliases and main itself.

- **21 ancestor refs.** Their commits are reachable from pinned main (`git merge-base --is-ancestor HEAD BASE`, substituting each pinned object). Later changes to that work are intentional history to inspect in the baseline inventory.
- **64 equal trees.** The branch-head tree, including paths, object IDs and modes, is identical to a commit reachable from pinned main. The witness is the matching source commit. This covers squash integrations even where the branch commit is not reachable.
- **4 equal path sets.** At the associated PR integration commit every path touched from the merge base to the branch tip has the same content and mode as the tip. Paths were derived without rename detection, including both sides of any rename, then compared with `git diff --exit-code TIP INTEGRATION -- <paths>`. Other paths changed during integration.
- **13 remaining refs.** These required PR disposition, successor history and semantic inspection. The table and the retained obligations below document each result. A pull-request number in the second column identifies a matching advertised PR head, or is explicitly given as a related case in the disposition.

Branch incorporation proves custody in source history. The source-file inventory and practical tests establish what is present and exercised in MAPSL.
