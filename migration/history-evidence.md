# Historical source reconciliation

## Custody and scope

The pinned Git tree contains 2,359 paths in `legacy/`, 115 curated snapshot paths and nine migration documents. Of these 2,483 paths, 113 already had reference dispositions and the source migration README had an adapted destination. The remaining 2,369 have per-path source links in the inventory. The original operator retained the archive in October 2026. Its task rows, reference databases, binary bundles, host logs, handoff snapshots and inbox traffic remain in source custody. They serve incident reconstruction when specifically needed. They supply no new authority or current tasks. [Source retention decision](https://github.com/BigCatMellow/MAPS_Lean/blob/605ce610e0be3334d1da7af2a7c6f5912b6cc05f/legacy/README.md) · [Original promotion and dataset ledger](https://github.com/BigCatMellow/MAPS_Lean/blob/605ce610e0be3334d1da7af2a7c6f5912b6cc05f/migration/LEGACY_PROMOTION_LEDGER.md)

We used source Git blobs, task JSON and the prior audits. The review screened the story-bearing collections by status, observation, subject, target and cited task. It followed contradictions and material findings to targeted primary records. Historical reviews, release checklists, generated plots, project fixtures and machine artifacts were grouped by purpose. Grouped custody does not certify that every private or historical claim was independently reproduced. For each claim below, the successor roadmap program owns future action under its existing triggers. The [master roadmap](../work/roadmaps/00-MASTER-MAPS-CAPABILITY-ROADMAP.md) owns priorities.
